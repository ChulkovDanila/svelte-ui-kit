# Components

List of available components in Svelte UI Kit.

## Button

Animated button component with slide and arc animations.

### Installation

See [INSTALL.md](./INSTALL.md) for detailed installation instructions.

### Quick Start

```svelte
<script>
  import { Button } from '$lib/components/ui/Button';
</script>

<Button>Click me</Button>
```
