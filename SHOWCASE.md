## 🎯 Animation Types Explained

### Slide Animation

The **Slide** animation moves text horizontally across the button:
- Text slides **right** when hovered
- New text slides in from the **left**
- Smooth, professional movement
- Perfect for clean, modern designs

### Arc Animation

The **Arc** animation moves text in a curved path with rotation:
- Text moves in a **semicircle** path
- Includes **rotation** effect for dynamic feel
- More playful and expressive
- Great for creative, eye-catching designs
